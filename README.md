
# Superstore Sales Dashboard

## About This Project

In this task, I worked on the Superstore dataset and created different visualizations using Power BI. The purpose of this project was to understand the sales performance of the business and present the data in a simple and meaningful way.

## Tools Used

* Power BI
* Superstore Dataset

## Visualizations Created

* Sales by Category
* Profit by Region
* Sales by Segment
* Sales by Year
* Total Sales Card
* Total Profit Card

## What I Learned

Through this project, I learned how to create charts and dashboards in Power BI. I also learned how to identify useful insights from data and present them in a visual format.

## Key Findings

* Technology category had the highest sales.
* West region generated the highest profit.
* Consumer segment contributed the largest share of sales.
* Sales increased over the years.

## Conclusion

This dashboard helped me understand how data visualization can be used to analyze business performance and communicate insights more effectively.
